Это простой CLI-инструмент для упаковки 360° эквидистантных (equirectangular) панорам в один самостоятельный HTML-файл. 
Идеально подходит для отправки друзьям через мессенджеры или для офлайн-просмотра.

<!-- ####################################################################################################### -->

## 💡 Главная идея
Философия **html360** заключается в том, чтобы сделать 360°-панораму такой же простой и универсальной, как обычный файл изображения или видео. 

Вы можете открыть её на любом устройстве без необходимости:
- Устанавливать специальный софт (**достаточно любого современного веб-браузера**).
- Зависеть от внешних сервисов (Google Фото, Яндекс Панорамы и т. д.).
- Подключаться к интернету

## 🚀 Быстрый старт
Установите инструмент глобально:
```
npm install -g html360
```
Или запустите его без установки с помощью `npx`:
```
npx html360 panorama_1.jpg panorama_2.jpg
```

## ✨ Интеграция в Windows

Одна из самых крутых фишек **html360** — это возможность упаковывать панорамы прямо из Проводника (File Explorer).

![Превью контекстного меню Windows](assets/windows-integration-v2.gif)

### Настройка контекстного меню
После глобальной установки пакета выполните эту команду **один раз**, чтобы добавить **html360** в меню «Отправить» (Send To):
```
html360 install-menu
```
### Удаление контекстного меню
```
html360 uninstall-menu
```

## ✨ Создание интерактивных 3D-туров
Превратите коллекцию панорам в связанный 3D-тур, не выходя из браузера:

![3D-Tour-Editor-Demo](assets/3d-tour-editor.gif)

- **Визуальный редактор:** добавляйте точки перехода и инфо-зоны (info-spots) в несколько кликов.
- **Умное автодополнение:** связанные панорамы индексируются автоматически, что позволяет легко соединять сцены через относительные URL-адреса.
- **Информативные точки:** встраивайте текстовые описания и внешние веб-ссылки прямо в ваше 360° пространство.

### Как это работает:

1. **Пакетная обработка:** запустите `html360 *.jpg`, чтобы сгенерировать HTML-файлы для всех ваших комнат.
2. **Вход в режим редактирования:** откройте любую панораму и включите **Редактор** (через правый клик мыши).
3. **Наведение и добавление:** используйте появившееся **перекрестие прицела**, чтобы указать на дверь, выберите «Add Panorama» и выберите нужную комнату из **умного списка автодополнения**.
4. **Добавление контекста:** расставьте инфо-точки с текстом, чтобы сделать тур информативным.
5. **Сохранение результата:** нажмите **Save**. Новый самостоятельный HTML-файл мгновенно сгенерируется со всеми вашими хотспотами и запеченными переходами внутри.

## ✨ Автоматическая галерея панорам

` 📸 Панорама 1  📄 [← Назад]  🔢 2 / 5  📄 [Вперед →]  📸 Панорама 3 `

При пакетной обработке нескольких фотографий за один раз вы можете просматривать их как непрерывную бесшовную фотогалерею. Вам не нужно вручную связывать сцены — **html360** позаботится об этом автоматически.

Генератор запекает интуитивно понятные кнопки-стрелки **Вперед** (Forward) и **Назад** (Back) прямо в каждый самостоятельный HTML-файл.

- **Как фотоальбом:** листайте панорамы точно так же, как обычные фотографии.
- **Умный счетчик:** отображает элегантный индикатор «Сцена X / Всего» прямо между стрелками навигации, чтобы вы всегда знали, где находитесь.

### Как включить

Эта функция управляется через глобальную конфигурацию. Запустите `html360 config` в терминале и включите параметр `useAutoNav`.

*(Подробнее о том, где хранятся настройки, читайте в разделе **Глобальная конфигурация** ниже).*

## ✨ Оптимизация в 8K

По умолчанию **html360** использует библиотеку **Sharp** для сжатия панорам высокого разрешения с сохранением **8K** (8192×4096).

- **До:** ~50 МБ (исходный JPEG)
- **После:** **~8 МБ** (оптимизированный WebP внутри HTML)

Это обеспечивает **сокращение размера файла примерно на 80%**, благодаря чему ваши интерактивные 360° сцены загружаются невероятно быстро, и их легко отправлять другим.

## ✨ Режим оригинала

Для целей архивирования или просмотра на мощных ПК используйте режим оригинала (флаг `-r` или `--raw`). Он пропускает любое сжатие и встраивает ваш исходный файл в HTML бит-в-бит.

> ### 💡 Совет
>Используйте **режим 8K** для отправки на мобильные устройства и в веб, а **Raw Original** — для личной коллекции высокого качества, где важен каждый пиксель.
>
>**Режим 8K** настолько точен, что визуальные различия практически незаметны даже на панорамах **12K (12000×6000)**, в том числе при умеренном масштабировании. Значительные визуальные улучшения в режиме **Raw Original** становятся заметны только на источниках сверхвысокого разрешения — от **21K (21456×10728)** и выше, особенно когда требуется сохранить тончайшие текстуры и оригинальную глубину цвета.

## ✨ Мультиразрешение: Гигапиксельные панорамы

Забудьте об ограничениях оперативной памяти браузера или видеокарты. **html360** теперь умеет обрабатывать изображения экстремального разрешения (масштаба NASA/ESO 40K+) путем их нарезки на тысячи умных интерактивных фрагментов (тайлов).

- **За пределами 8K:** автоматически обходит лимиты `MAX_TEXTURE_SIZE` в современных браузерах.
- **Загрузка по требованию:** вьюер загружает только те тайлы, на которые вы смотрите в данный момент. Это делает перемещение по гигантским гигапиксельным сценам мгновенным и плавным.
- **Синхронный конвейер:** нарезка выполняется последовательно, что защищает ваш процессор и оперативную память от перегрузки при работе с массивными исходными файлами.

```bash
html360 multires massive_pano_01.tif massive_pano_02.tif ...
```

*Этот режим поддерживает те же параметры, что и оригинальный `generate.py` (haov, vaov, voffset, horizon и т. д.), но с оптимизированными настройками по умолчанию для максимального качества «из коробки».*

### Профессиональный мультирез-режим

Режим **мультиразрешения (Multiresolution)** — это функция «тяжелой артиллерии», и работает она иначе, чем стандартный интерфейс **html360**:

1. **Нарушение правила «одного файла»:** вместо одного автономного HTML-файла этот режим генерирует папку, содержащую тысячи фрагментов изображений. Это технически необходимо, чтобы браузеры могли «переваривать» гигапиксельные изображения по кусочкам.
2. **Требуется веб-хостинг:** из-за политики безопасности браузеров (CORS) вы не можете просто дважды кликнуть по `index.html` на диске. Результат должен быть загружен на сайт или запущен через локальный веб-сервер.
3. **Специфические сценарии использования:** используйте этот режим для профессиональных веб-проектов, где экстремальная детализация важнее возможности быстро отправить один файл через мессенджер.

### Что под капотом

В то время как **html360** управляет CLI и шаблонами, вся основная тяжелая работа выполняется проверенным временем скриптом `generate.py` из проекта Pannellum.

- **Портативность:** мы адаптировали оригинальный скрипт для работы в экосистеме **Node.js** и упаковали его в **готовые бинарные файлы** для Windows, Linux и macOS.
- **Ноль зависимостей:** вам **не нужно** устанавливать Python. Все предварительно скомпилировано и поставляется через наш пакет `@html360/gen`.
- **Умные настройки по умолчанию:** мы тщательно настроили базовые параметры (например, качество по умолчанию установлено на 95%), чтобы ваши гигапиксельные туры выглядели безупречно без ручной настройки.

> ### 💡 Совет
> Чтобы по-настоящему прочувствовать мощь **бесконечного зума**, мы рекомендуем использовать исходные изображения высокого класса от **60K (60 000 x 30 000 px)** или выше. Хотя стандартные панорамы тоже выглядят хорошо, только в **гигапиксельном масштабе** вы сможете приближать далекие горизонты и обнаруживать микроскопические детали — например, читать дорожный знак с расстояния в километр — без какой-либо пикселизации. **Pannellum** берет на себя всю тяжелую работу по нарезке, так что не бойтесь больших размеров!

## ✨ Сохранение

Действие **Save** фиксирует все текущее состояние вашей панорамы и запекает его в HTML-файл.

### Что сохраняется:

- **Дефолтный вьюпорт:** точное стартовое положение камеры (панорамирование, наклон и зум).
- **Интерактивные 3D-туры:** все переходы между сценами, ссылки и дверные соединения.
- **Информационные точки:** каждая инфо-точка, текстовое описание и внешняя веб-ссылка.
- **Кастомные метаданные:** название панорамы, имя автора и пользовательские конфигурации.

<!-- ####################################################################################################### -->

## ✨ Сохранение в режиме «Только для чтения»
**Режим «Только для чтения»** — это встроенная функция безопасности в **html360**, разработанная для финализации и защиты ваших 3D-туров перед их передачей клиентам, заказчикам или публикацией в сети.

По умолчанию каждая HTML-панорама, созданная с помощью **html360**, содержит мощный встроенный редактор, который позволяет любому пользователю добавлять хотспоты, изменять стартовые углы камеры и точки интереса. Это идеально подходит для разработки, но обычно проект нужно «заморозить» перед сдачей.

### Как это работает

- Нажатие кнопки **Save as Read-Only** запекает все текущие ракурсы и хотспоты в финальный HTML-файл, полностью скрывает все элементы управления редактированием, панели конфигурации и меню из интерфейса просмотра получателя.

## ✨ Сведения о панораме

Внутри редактора вы найдете кнопку **«Edit Details»** (Редактировать сведения). Она позволяет задать метаданные для вашей панорамы:

- **Tab Title** — название вкладки браузера.
- **Panorama Title** — название вашей панорамы.
- **Author** — указание автора фотографии или компании прямо рядом с названием.
- **Author URL** — превращает имя автора в кликабельную гиперссылку, ведущую на портфолио или сайт.

## ✨ Интеграция с картами и GPS

В **html360** появилась возможность привязывать панорамы к географическим координатам. Теперь можно в один клик перейти из плеера на внешнюю карту к точной локации, где был сделан снимок.

### Новые параметры конфигурации
Для автоматизации процесса при генерации панорам добавлены два флага:
- **`addGps`** (по умолчанию `false`): Активирует автоматическое извлечение GPS-данных из EXIF метаданных фотографий. Отключен по умолчанию, чтобы пользователи случайно не опубликовали приватные координаты.
- **`mapUrlTemplate`** (по умолчанию пустой): Задает шаблон ссылки для перехода на карту. При настройке в CLI можно выбрать один из готовых пресетов (**Google Maps**, **Яндекс Карты**, **Nakarte.me**) или указать свой кастомный вариант.

Если включить `addGps` и выбрать `mapUrlTemplate`, утилита автоматически сгенерирует прямые ссылки на карты для всех обрабатываемых фотографий.

### Работа в веб-редакторе
Управлять локациями можно вручную прямо в браузере после создания панорамы:
- В режиме редактирования добавлена отдельная кнопка для настройки картографических данных.
- В модальном окне можно задать или изменить **Широту (Latitude)**, **Долготу (Longitude)** и **Шаблон (mapUrlTemplate)**. Итоговый URL пересчитывается мгновенно при изменении любого поля.

### Режим просмотра
Если для панорамы сформирован URL карты, в левом верхнем углу (под названием и автором) появится интерактивная кнопка. Клик по ней откроет карту с точкой, где была снята панорама.

## ✨ Глобальная конфигурация
Сэкономьте время, настроив свой универсальный глобальный профиль. Вы можете один раз указать свои данные автора, и **html360** будет автоматически встраивать их во все будущие создаваемые панорамы.

```bash
html360 config
```

### Настройки конфигурации

| Параметр | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `tabTitle` | `string` | `image name` | Название вкладки браузера. |
| `title` | `string` | `""` | Название вашей панорамы. |
| `author` | `string` | `""` | Имя автора панорамы. |
| `authorUrl` | `string` | `""` | Ссылка на профиль или сайт автора. |
| `useImageNameAsTitle` | `boolean` | `false` | Автоматически использовать имя файла изображения в качестве названия панорамы. |
| `useAutoNav` | `boolean` | `false` |  Автоматически включать галерейную навигацию «Вперед/Назад».  |
| `addGps` | `boolean` | `false` | Включает автоматическое извлечение GPS-координат из EXIF-метаданных фотографий. Отключен по умолчанию во избежание случайной утечки приватных локаций. |
| `mapUrlTemplate` | `string` | `""` | Задает шаблон ссылки для кнопки перехода на карту. Можно указать собственную строку или выбрать один из готовых пресетов (**Google Maps**, **Яндекс Карты**, **Nakarte.me**). |

### Расположение конфига
Глобальный файл конфигурации хранится в вашей домашней директории пользователя:
* **Windows**: `%USERPROFILE%\.html360.json`
* **macOS / Linux**: `~/.html360.json`
